# Security Policy

## Supported Versions

Generally, only the latest version of Trusted Shops Easy Integration for WooCommerce has continued support. If a critical vulnerability is found in the current version of Trusted Shops Easy Integration for WooCommerce, we may opt to backport any patches to previous versions.

## Reporting a Vulnerability

Trusted Shops Easy Integration for WooCommerce is an open-source plugin for WordPress. Please report security bugs found in the source code of the plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/1b34d5e3-c05d-4a86-ac92-44e0225e04ac). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
